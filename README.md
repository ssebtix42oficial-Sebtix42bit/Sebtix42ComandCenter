⚡ Sebtix42 Command Center (HQ)
Sebtix42 Command Center es un panel de control estático y optimizado, diseñado especialmente para la gestión integral de producción de contenido para el canal de YouTube de Sebtix42.
Permite centralizar todas las tareas del canal en una sola interfaz moderna, rápida y totalmente adaptable.
________________________________________
🔥 Características Principales
•	📊 Dashboard General: Resumen del progreso semanal, tareas pendientes y estado de publicación del canal.
•	🎬 Tablero Kanban de Producción: Organiza las ideas de videos a través de 5 etapas (💡 Ideas, 📝 Guión, 📹 Grabación, ✂️ Edición, 🚀 Listo).
•	🎨 Identidad Visual & Paletas: Guarda y copia rápidamente los códigos hexadecimales (HEX) de los colores oficiales de tu marca.
•	📂 Gestión de Assets con Descarga: Importa plantillas, sobrecapas o imágenes y descárgalas en cualquier momento para reutilizarlas.
•	🎵 Verificación de Copyright: Módulo de prueba para evaluar la seguridad de pistas de audio antes de utilizarlas en tus producciones.
•	📈 Contador de Suscriptores: Seguimiento de métricas clave personalizables.
•	💾 Persistencia de Datos Local: Guardado automático en el navegador mediante localStorage.
